# Dead by Daylight Loadout Toolkit — feature reference

Dead by Daylight Loadout Toolkit groups character groups, loadout profiles, and session notes in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Character groups | Character-related parameters and the settings associated with the selected category. |
| Loadout profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Session notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
